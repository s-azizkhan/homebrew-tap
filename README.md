# s-azizkhan Homebrew tap

```sh
brew install --cask s-azizkhan/tap/dusk
```

| Cask | Description |
|---|---|
| [dusk](https://github.com/s-azizkhan/dusk-mac) | Free, open-source blue light filter and flicker-free screen dimmer for Mac |

## Windows

Homebrew is Mac and Linux only. Dusk for Windows is a single exe, no installer:

1. Download `Dusk.exe` from [dusk-windows releases](https://github.com/s-azizkhan/dusk-windows/releases).
2. Run it. Dusk lives in the system tray.

It's a preview. Source and notes: [s-azizkhan/dusk-windows](https://github.com/s-azizkhan/dusk-windows).
